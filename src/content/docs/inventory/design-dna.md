This is the rule I set for myself: don't just bookmark a site you admire — write down *why*. A link is a dead end. A reason travels. "Awwwards, for how motion shapes perceived speed" is something an agent (or future me) can apply to a brand-new project; "I like Awwwards" is not.

So this isn't a gallery. It's a taste graph — each reference paired with the principle it taught me.

## The references

**[SiteInspire](https://www.siteinspire.com/)** — The reference for how whitespace and typography play off each other. I come here to re-learn the same lesson: negative space frames the content. When a layout feels wrong, the answer is usually more room, not more stuff.

**[Awwwards](https://www.awwwards.com/)** — I study this for motion. Specifically how a considered transition changes *perceived* performance — the way the right animation makes an interface feel faster and more alive than the same interface sitting still. It's also my benchmark for craft at the high end.

**[Land-book](https://land-book.com/)** — My reference for landing-page structure. The best pages here commit to one message and sequence it, instead of cramming three messages above the fold. Good for studying hierarchy and how a scroll should be paced.

**[CSS Design Awards](https://www.cssdesignawards.com/)** — A bar for execution. Less about the big concept, more about how cleanly something is actually built and finished. The details here are what separate competent from considered.

**[Web Design Museum](https://www.webdesignmuseum.org/)** — Perspective, mostly. Seeing how the web really looked across decades is a vaccine against mistaking this year's trend for a law of nature. Restraint and clear hierarchy keep showing up across eras; the fashionable parts don't.

## The principle underneath

Borrow the principle, not the trend. A trend has an expiration date. The reason a thing worked — that's the part worth keeping, and the part worth writing down.
