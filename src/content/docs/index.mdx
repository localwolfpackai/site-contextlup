## A different kind of portfolio

Most portfolios show the result — here is the thing I built. This one shows the engine: the rules, the logic, and the taste that produced it.

Point an agent at this site and it doesn't read a résumé. It instantiates a methodology. The same content you're reading as prose is served to machines as structured JSON at [`/api/manifest.json`](/api/manifest.json) — one source of truth, two surfaces, no drift.

```text
GET /api/directives.json   every hard constraint, flattened
GET /llms.txt              a plain-text map of the brain
```
